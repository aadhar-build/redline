# The rule for a risk that comes from several sentences

Type: grilling
Status: resolved
Blocked by: 10

## Question

OQ10 (ADR 0001). Default Red line 2 (auto-renewal in one sentence, exit fee in another) and Default Red line 4 (no cap sentence anywhere) depend on it. Can a flag cite more than one Source sentence, each checked, and how is an absence (no cap) shown, given ADR 0001 rules out Missing protection flags?

## Answer

Product owner, 2026-10-31 (asked in session). A flag may cite several Source sentences; each is checked word for word, and the flag is withheld if any one fails. For Default Red line 4, the flag cites the liability or indemnity sentence and states 'no cap appears in the document' labelled Redline's judgment. Closes OQ10.
