# Where withheld flags are shown and whether they block a Clean result

Type: grilling
Status: resolved
Blocked by: 02

## Question

OQ11 and OQ12. Is the withheld count shown to the Reviewer or only recorded? Can a review be a Clean result when flags were withheld, given that a document whose only Don't sign as written flags failed the Source sentence check would otherwise get one? Gates implementation tickets 16 and 20.

## Answer

Product owner, 2026-10-31 (asked in session). The withheld count is shown to the Reviewer ('N flags withheld because their source couldn't be found'), and any withheld flag blocks a Clean result. Closes OQ11 and OQ12.
