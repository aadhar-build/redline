# What Default Red line 3 covers

Type: grilling
Status: resolved
Blocked by: 02

## Question

OQ3 and OQ8. Does 'as amended from time to time' match Default Red line 3 (ADR 0007 calls it that Red line in another form), making it Don't sign as written so marking it reviewed cannot give a Clean result? Does a fee escalator written into the contract match, or only a change the Counterparty makes later?

## Answer

Product owner, 2026-10-31 (asked in session). Both match Default Red line 3, so both are Don't sign as written: terms 'as amended from time to time', and fee escalators already written into the contract. Marking an 'as amended' reference reviewed therefore never produces a Clean result. Closes OQ3 and OQ8.
